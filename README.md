# Creative Writing Assistant Suite

웹소설, 시나리오, 게임 등 모든 창작물 자동 생성 및 보조 프로그램

## 기능

### 📖 웹소설 창작
- **플롯 생성**: 3막 구조, 복선 배치, 반전 아이디어
- **캐릭터 생성**: 이름, 성격(MBTI), 외모, 배경, 능력
- **세계관 구축**: 판타지/SF 세계관, 마법 시스템, 종족 설정
- **대화 생성**: 성격별 대화 패턴, 상황별 대화
- **장면 묘사**: 전투, 로맨스, 일상 장면
- **파워 시스템**: 헌터, 무공, 초능력 시스템

### 🎬 시나리오 창작
- **영화 시나리오**: 3막 구조, 씬 구성, 카메라 앵글
- **드라마 시놉시스**: 회차별 구성, 인물 관계도
- **웹툰 스토리보드**: 컷 구성, 대사 배치

### 🎮 게임 창작
- **퀘스트 생성**: 메인/서브 퀘스트, 보상 시스템
- **NPC 생성**: 대화 스크립트, 상점 아이템
- **던전 디자인**: 층별 구조, 몬스터 배치, 보물
- **TRPG 도구**: 랜덤 조우 테이블

### 💡 아이디어 생성
- **소설 아이디어**: 테마/세팅 조합
- **제목 생성**: 장르별 템플릿, 클릭베이트 제목
- **플롯 트위스트**: 반전 유형, 복선 구성

## 설치

### 필요 요구사항
- Python 3.8 이상
- pip

### 설치 방법

```bash
# 저장소 클론
git clone https://github.com/junggyeol4444/auto.git
cd auto

# 의존성 설치
pip install -r requirements.txt

# 프로그램 실행
python main.py
```

## 사용 방법

1. `python main.py` 명령으로 프로그램 실행
2. 좌측 메뉴에서 원하는 기능 선택
3. 필요한 설정 입력 후 "생성" 버튼 클릭
4. 생성된 내용을 편집하고 저장 또는 내보내기

## 프로젝트 구조

```
Creative_Writing_Assistant/
├── main.py                 # 메인 진입점
├── config.json            # 설정 파일
├── requirements.txt       # 의존성 목록
├── modules/               # 핵심 모듈
│   ├── database.py       # 데이터베이스 처리
│   ├── webnovel/         # 웹소설 생성 모듈
│   ├── scenario/         # 시나리오 생성 모듈
│   ├── game/             # 게임 생성 모듈
│   └── ideas/            # 아이디어 생성 모듈
├── gui/                   # GUI 인터페이스
│   ├── main_window.py    # 메인 윈도우
│   └── editor_window.py  # 편집 윈도우
├── templates/             # 템플릿 파일
└── output/                # 출력 파일
```

## 주요 특징

- ✅ **완전한 오프라인 작동**: AI API 없이도 템플릿 기반 생성 가능
- ✅ **모던 GUI**: customtkinter 기반 깔끔한 인터페이스
- ✅ **데이터베이스**: SQLite로 프로젝트 저장 및 관리
- ✅ **한국어 지원**: 완전한 한국어 UI 및 콘텐츠
- ✅ **다양한 장르**: 판타지, 로맨스, 무협, SF 등
- ✅ **파일 내보내기**: TXT 형식 지원

## 기술 스택

- **Python 3.8+**
- **customtkinter**: 모던 GUI
- **SQLite**: 데이터베이스
- **Pillow**: 이미지 처리
- **python-docx**: 문서 생성 (선택적)
