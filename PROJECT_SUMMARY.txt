YouTube Auto Content Generator - Project Summary
================================================

Project Type: Python Application
Purpose: Automated YouTube video content generation from web-crawled data
Language: Python 3.8+
GUI Framework: CustomTkinter

Core Features:
--------------
1. Web Crawling
   - News sites: Naver News, Daum News
   - Wiki sources: Wikipedia, NamuWiki
   - Structured data collection

2. Content Restructuring
   - 3 template types: News Report, Informational, Storytelling
   - Automatic script generation
   - Natural Korean language processing

3. Text-to-Speech
   - gTTS (Google TTS) - online
   - pyttsx3 - offline
   - Custom TTS support (Coqui TTS framework)

4. Video Creation
   - MoviePy-based video generation
   - Audio-video synchronization
   - Background image/color support

5. YouTube Integration
   - Automatic video upload via YouTube Data API v3
   - SEO-optimized metadata generation
   - Privacy control and thumbnail support

6. User Interface
   - CustomTkinter-based GUI
   - Real-time progress tracking
   - Intuitive topic and style selection

Known Limitations:
------------------
- gTTS requires internet connection
- MoviePy text overlay requires ImageMagick (optional)
- YouTube API has daily quota limits
- Web crawlers may need updates if site structures change

Security Considerations:
------------------------
- credentials.json should never be committed (in .gitignore)
- Respect robots.txt and rate limiting
- Comply with content licensing and fair use
- Review YouTube API Terms of Service

Installation:
-------------
1. Clone repository
2. Install dependencies: pip install -r requirements.txt
3. Run setup: python setup.py
4. (Optional) Configure YouTube API credentials
